# 📡 Схема подключения камеры (испытательный стенд)

```
                    ┌─────────────────────┐
                    │   РОУТЕР (WiFi + LAN)│
                    │ 192.168.1.1 (обычно) │
                    └──┬─────────┬─────────┘
                       │ LAN-порт│ WiFi
        ┌──────────────▼──┐      │
        │  PoE ИНЖЕКТОР   │      │
        │  (питание 48V)  │      │
        └──────────────┬──┘      │
                       │ RJ45     │
        ┌──────────────▼──┐      │
        │   IP-КАМЕРА     │      │
        │  (RJ45 разъём)  │      │
        └─────────────────┘      │
                                 │
                    ┌────────────▼──────────┐
                    │  ПК (Hermes, YOLO)    │
                    │  WiFi → тот же роутер │
                    │  RTSP: rtsp://<IP>    │
                    └───────────────────────┘
```

## Подключение (завтра утром)

1. **Камера** → RJ45-кабель → **PoE-инжектор** (вход LAN)
2. **PoE-инжектор** → второй RJ45 → **роутер** (свободный LAN-порт)
3. **ПК** → WiFi → **тот же роутер** (уже подключён)
4. Включить инжектор в розетку — камера получит питание и IP по DHCP

## Как я найду камеру

Камера получит IP от роутера (обычно 192.168.1.x или 192.168.0.x).
После подключения запустим сканер — он найдёт камеру автоматически:

```bash
python scripts/scan_cameras.py          # сканирует 192.168.1.0/24 и 192.168.0.0/24
python scripts/scan_cameras.py --subnet 192.168.1.0/24 --ports 554,80,8000,8080,37777
```

**Что сканер делает:**
- Пингует все IP в подсети
- Проверяет открытые порты: **554** (RTSP), 80/8080 (веб-интерфейс), 8000, 37777 (Dahua/XMeye)
- По портам и баннеру угадывает производителя (Hikvision/Dahua/другой)
- Выдаёт готовый `rtsp://user:pass@IP:554/stream1` для конфига

## Стандартные RTSP-пути (по производителю)

| Производитель | Путь |
|---|---|
| Hikvision | `rtsp://user:pass@IP:554/Streaming/Channels/101` |
| Dahua / XMeye | `rtsp://user:pass@IP:554/cam/realmonitor?channel=1&subtype=0` |
| Uniview | `rtsp://user:pass@IP:554/unicast/c1/s0/live` |
| Универсальный | `rtsp://user:pass@IP:554/stream1` или `/live` или `/ch0` |

> Если не знаешь пароль камеры — он обычно на наклейке снизу, либо
> стандартный (admin/admin, admin/12345). Для испытаний подойдёт любой.

## Проверка после подключения

```bash
# 1. Пингуем роутер (связь есть)
ping 192.168.1.1

# 2. Сканируем камеру
python scripts/scan_cameras.py

# 3. Смотрим поток (должно открыться окно с видео)
python tools/rtsp_preview.py rtsp://user:pass@192.168.1.50:554/stream1

# 4. Запуск охраны (прототип)
python demo_prototype.py --source rtsp://user:pass@IP:554/stream1
```

## Если камеру не видно

- Камера и ПК должны быть в **одной подсети** (192.168.1.x = 192.168.1.x)
- Некоторые камеры по умолчанию имеют **статический IP** (192.168.1.108 у Hikvision, 192.168.1.10 у Dahua) — сканер найдёт
- Если совсем не видно: подключи камеру кабелем напрямую к ПК (ПК→камера, без роутера), поставь ПК IP 192.168.1.100/24 — и сканер увидит её по статическому адресу
